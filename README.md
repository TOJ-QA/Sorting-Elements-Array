# 📖 Overview

This project demonstrates how to sort the elements of an array in **ascending order** using Java.

The program stores a collection of numbers in an array, sorts them, and displays the results. Sorting data is one of the most common operations in programming and is used in searching, reporting, and data analysis.

This exercise was completed as part of my **Cloudberry Java Automation Bootcamp** to strengthen my understanding of arrays, loops, and sorting algorithms.

# 💻 Sample Code

```java
import java.util.Arrays;

public class SortingElementsArray {

    public static void main(String[] args) {

        int[] numbers = {8, 3, 12, 5, 1, 9};

        System.out.println("Original Array:");
        System.out.println(Arrays.toString(numbers));

        Arrays.sort(numbers);

        System.out.println("Sorted Array:");
        System.out.println(Arrays.toString(numbers));
    }
}
```
